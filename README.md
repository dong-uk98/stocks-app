# 주식 워치리스트 — 조회용 앱

폰에서 워치리스트를 보기 위한 정적 페이지다. **여기 있는 파일은 전부 생성물이고,
손으로 고치지 않는다** — 원본은 비공개 원장 저장소의 `docs/` 이고 `tools/publish_app.py`
가 그대로 복사해 온다.

- 조회 전용이다. 보유 수량 입력과 공유 저장은 원장(아티팩트)에 있다.
- `data.json` 에 담기는 것: 시세 · 저평가 시작가 · 비율 · 순점 · 적용 규칙 · 산출 근거.
  **보유 수량과 평단가는 들어가지 않는다.**
- 오프라인 조회는 `sw.js` 가 맡는다. 값은 네트워크를 먼저 보고, 실패하면 받아둔 값을
  보여주면서 '오프라인'이라고 적는다.

갱신 시각은 페이지 상단에 적힌다.
